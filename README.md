# 观澜 · 有框架的个人研究工作台

为有一定金融基础、经常阅读深度内容但研究方法尚零散的人，提供「宏观 → 贵金属 → A 股公司」的研究骨架。把新材料放到已有问题下，保存原文、验证条件与修订过程。

**当前：v0.8.1 本地单用户版本。** 完成工程修复与本地回归；AI仍为实验性辅助，人工盲评与真人试用尚未开展。未部署线上体验站。

先看[最新使用说明书](docs/使用说明书-v0.8.1.md)、[发布验收及限制](docs/发布验收-2026-10-13.md)和[PRD发布状态补充](docs/PRD-v0.3.md)。

## 开始使用

Mac本机安装依赖后，可双击 [启动原型.command](prototype/启动原型.command)，在浏览器打开 `http://127.0.0.1:8765`。

新环境首次安装（Python 3.12）：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server/app.py --open
```

也可直接打开 [独立 HTML](prototype/观澜-可交互原型.html)，无需服务即可浏览带采集日期的数据/新闻快照、叙事模板，并体验材料整理、归档、修订和备份；**离线版没有公开数据刷新、模型调用和技术指标计算**。两个地址的浏览器存储不共享，可通过 JSON 备份合并记录。

建议第一次点首页「走一遍材料归档」，按三步完成一次示例，再到框架中查看归档位置。

## 两条工作流

1. **日常查看**：选择框架问题 → 查看对应数据与财经信息 → 阅读原文 → 记录研究证据。
2. **主动研究**：导入文字 → 手动或 AI 辅助拆解 → 核对引用与归类 → 确认归档 → 建立观察主题 → 后续修订。

宏观包含增长、通胀、政策、货币金融。贵金属区分黄金与白银，产业链展示生产角色，并单独说明持有与交易参与者。公司页拆分经营、估值与技术指标。叙事观察关联具体框架节点，不独立堆积观点。

## 实际能力

| 能力 | 当前状态 |
|---|---|
| 框架、产业链地图、材料三步归档 | 已实现；原文定位、确认、修订历史可用 |
| 公开宏观数据 | 实测 PMI、CPI/PPI 同比、M2 同比、社融增量、LPR 及 3 条 FRED 序列；另有上金所金银合约价格及 GLD/SLV 持有量 |
| 新闻 | 实测财联社、新浪、东方财富、两家样例公司新闻及美联储 RSS；BLS RSS 403，明确显示失败 |
| 更新 | 本地服务运行期间，每个自然日检查一次；关闭服务后停止；可手动刷新 |
| 叙事与观察 | 4 个研究模板、2 个历史方法案例；主动采用后跟踪验证问题与里程碑，匹配新闻标题 |
| 公司 | 五个公司财务样本可按报告期及个人公司列表筛选；估值快照仍手动录入；五只代码支持历史行情，另可导入价格CSV |
| 技术指标 | 复用 TA-Lib 计算 MA20、RSI14、MACD(12,26,9)，样本不足留空 |
| AI | 已实现兼容接口和输出校验；已有单材料真实模型实验；稳定性未通过完整评估，人工确认后才归档 |
| 保存 | 浏览器 localStorage、JSON 导出/合并；保留旧版数据，不支持多人同步 |

贵金属现有少量年度供需摘要与两只 ETF 持仓；尚缺 GDP 分项、完整社融结构、完整贵金属供需与其他持仓、全市场 A 股自动行情/财报/公告、公众号/播客自动抓取。没有把未完成接口显示成在线，也不生成股票排名、收益预测或仓位建议。

## 复用与项目贡献

- [AKShare](https://github.com/akfamily/akshare)：1.19.1，MIT；实际复用国内宏观、上金所价格和财经新闻接口。接口可用性及内容使用条件仍取决于上游。
- [feedparser](https://github.com/kurtmckee/feedparser)：RSS 解析，6.0.12，BSD-2-Clause。
- [TA-Lib Python](https://github.com/TA-Lib/ta-lib-python)：成熟技术指标实现，0.6.8；许可证随安装包分发。
- [FRED](https://fred.stlouisfed.org/)、[美联储 RSS](https://www.federalreserve.gov/feeds/feeds.htm)：公开数据和原始新闻来源。
- [Open Notebook](https://github.com/lfnovo/open-notebook)：此前完成 7 项基础接口 PoC，**当前页面尚未与其存储集成**，不声称已复用整套产品。

本项目实现的是研究框架组织、材料到节点的映射、来源追溯、用户确认与修订流程，以及组件之间的连接。现成解析和计算能力不表述为独立原创。

方法卡来自用户提供材料的抽象转译；历史案例不作当前结论。未直接核验的书籍阅读稿不标为原书认证。公开样例为原创教学材料，实习材料全文、书籍全文和私人笔记不包含在本目录。

## 开发与验证

```sh
.venv/bin/python tests/test_backend.py
.venv/bin/python tests/test_providers.py
python3 scripts/package-prototype.py
```

浏览器验收使用 Playwright 与独立 Chrome，脚本位于 `tests/prototype-smoke.cjs`、`tests/extended-smoke.cjs` 和 `tests/v03-smoke.cjs`；浏览器路径为当前 Mac 环境，其他机器需修改。后者包含实时数据验收，需要联网且官方来源可访问。

源码：`prototype/dist/`；本地服务：`server/`；`scripts/package-prototype.py` 生成独立 HTML。旧版界面保存在 `prototype/archive-v0.1/`。

## 验证边界

产品发起者负责需求与范围取舍，AI 辅助实现和验证。当前完成的是可操作原型和部分技术链路，不是已验证的投资效果。后续记录真实用户反馈，结合验收结果更新 PRD 并整理公开项目材料；不预填未经测量的效率提升指标。
