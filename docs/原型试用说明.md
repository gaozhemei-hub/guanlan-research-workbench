# v0.4 原型试用说明

## 打开方式

推荐双击 `prototype/启动原型.command`。浏览器地址固定为 `http://127.0.0.1:8765`，关闭终端或按 Ctrl+C 会停止数据服务。

直接打开 `prototype/观澜-可交互原型.html` 可查看带日期的公开快照、叙事方法卡并离线整理材料，但不能刷新公开数据、调用模型或计算价格指标。不要将离线页面与本地服务页面当成同一份浏览器存储；可通过导出与合并转移记录。

## 第一次：用示例走完整条流程

1. 首页点击 **走一遍材料归档**。
2. 材料研读第 1 步展示原创教学材料：某种政策议题可能改变投资假设，但过程并不确定。点 **下一步：拆解与归类**。
3. 第 2 步核对 §2 原文、观点、归类位置与反证条件。默认放入 **宏观政策**。示例来自预置内容，未调用 AI。
4. 第 3 步检查归档位置；可勾选观察主题，并填写逗号分隔的新闻关键词。
5. 点击 **确认归档**，然后 **查看框架中的证据**。
6. 到 **叙事观察** 查看主题。命中数量只代表已接入新闻标题匹配，不是全网覆盖，更不是观点被证明。
7. 在证据卡上点击 **补充 / 修订**，填写修改及理由，查看前后对比，最后确认。旧版本保留。

示例会清楚标记为教学示例。它不代表真实政治事件或市场判断。

## 带入自己的材料

材料研读 → 新建材料 → 粘贴文字或导入 UTF-8 TXT/MD → 填写标题、类型及可选原文链接。

按空行分段，每次归档一条观点。一个材料可继续归档多条观点，各自关联不同节点。改动正文会清空旧拆解结果，避免把旧结论错误关联到新材料。未归档草稿在浏览器中保留。

未配置 API：按关键词给出候选框架位置，观点、问题与反证条件由你填写。

配置 API 后：点击 **AI 辅助拆解** 才发送当前材料正文和框架摘要，其他研究记录不会一并发送。最多返回 5 条建议，先选一条核对、修改，再确认归档。引文位置校验不是外部事实核查。

## 日常查看

- **宏观环境**：左侧选择增长、通胀、政策或金融，右侧切换框架、数据、相关信息和证据。
- **贵金属产业**：黄金和白银分别看；产业链地图展示角色和传导关系，不虚构企业供货关系。
- **A 股公司**：「财务面板」可直接查看山东黄金与盛达资源两个固定样本，选择同一报告期比较七项财务指标。个人研究公司则先手动添加对象与业务位置。在公司列表记录估值或上传价格 CSV，再去横向比较。估值、技术数据分别标日期和口径，不混成评分。
- **叙事观察**：先在「方法与研究起点」展开模板；点击采用、修改问题并保存后，进入「我的观察」。每个模板有三条验证里程碑，更新状态时需填写证据或理由。也可自行建立主题、暂停追踪、查看匹配信息并标已读。
- **数据与设置**：查看来源成功/失败状态、开启或关闭新闻显示、配置 AI 和备份。

新闻支持按当前问题／本层／全部、来源与标题关键词筛选；同日同标题折叠，不进行语义去重。公司新闻暂为山东黄金、盛达资源两个采集样例，不随自选公司自动变化，也不代表推荐。

新闻卡的“记录阅读后的证据”只带入标题与原文链接；请阅读原文后补正文，平台不会把标题当作全文。

## 价格 CSV

必须是 UTF-8 CSV，包含以下列；可多列，但只读取 `date`、`close`：

```csv
date,close
2026-01-05,10.20
2026-01-06,10.35
```

以上仅展示格式，不对应证券。最多 5,000 行、500 KB。重复日期、未来日期、无效或非正价格会拒绝；日期自动排序。需自行明确复权方式、币种和来源，并保证样本为连续可用交易数据。MA20 至少 20 个值，RSI14 至少 15 个值，MACD(12,26,9) 至少 34 个值。Hist = MACD − Signal，未乘 2。

记录估值快照时，至少填一个倍数，填写估值日期、财报截止期和来源。日期、币种与报告期不一致会提示不可直接排名；相同口径也不等于公司业务完全可比。

## 当前接通与未接通

已实测：PMI、CPI/PPI 同比、M2 同比、社融增量、LPR；两个公司样本的财务指标；上金所 Au99.99（元/克）、Ag(T+D)（元/千克）；FRED 的 DFII10、T10YIE、DTWEXBGS；财联社、新浪、东方财富与两个样例公司新闻；美联储 RSS；本地 TA-Lib 计算。

白银为延期交割合约，不能当作工业现货口径。PMI/CPI/M2 为月度指标；每日检查不会产生每天的新观察值。

BLS CPI 新闻实测返回 403；展示失败，不绕过访问限制。数据失败保留旧缓存，并显示最近成功时间。CSV 没有发布时间时明确标为“未提供”，不拿抓取时间替代。

未接通：GDP 分项、社融结构、贵金属供需与持仓、A 股自动行情财报公告、公众号与播客自动获取。AI 的真实调用等待本地配置与一次实际测试。

## 保存与旧数据

本版数据保存在当前浏览器的 `guanlan-workbench-v2`。首次使用检测到旧版 `guanlan-prototype-v1` 时，保留旧键，并在新版备份中保留旧记录；设置中可复制旧材料进入新版流程。

导出包含材料原文、草稿与修订，请自行保管。导入备份会合并不同 ID 的记录；相同 ID 保留当前记录，不覆盖。暂不提供跨浏览器自动同步，也不宣称多人并发编辑安全。
