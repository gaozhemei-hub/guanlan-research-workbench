# v0.8.1 发布验收

日期：2026-10-13。范围：本地单用户版本及可配置登录的容器。没有线上站点、人工盲评或真人试用结论。

## 本轮修复

- 行情优先腾讯、失败回退东方财富；整段时间窗来自一个成功来源，不拼接不同复权序列。来源、复权及缓存日期随结果保留。
- 浏览器写入失败时恢复最后一次成功保存的研究状态，停止成功提示及后续操作。材料草稿暂留内存，页面明确提示导出；其他表单需重新填写。
- AI 等待期间的手工编辑不被迟到响应覆盖；更换段落后撤销引用已校验标记。引用校验仅容许 Markdown 加粗标记差异，不替代事实核查。
- 里程碑延期必须填写未来日期；到期重新进入待办，暂停的观察不提醒，保留复核历史。
- 备份字段与 HTML 输出转义、JSON 请求检查、引用长度检查。
- 非本机监听要求服务端登录配置。静态资源 GET 与 HEAD 均验证登录和 Host；最小健康检查 GET /healthz 公开。

## 证据与边界

候选副本先复跑原63项后端测试，再补充HEAD鉴权测试；合并后实际结果见本次运行记录。浏览器回归覆盖15项测试方法，其中写入失败一项含8个子场景。当前9个冒烟脚本均在明确关闭真实AI的环境执行通过；旧v0.1脚本只适用于保留的旧版原型，不纳入v0.8.1套件。

工程测试包含模拟AI、合成价格序列和公开缓存，不是用户试验，也不是投资效果验证。完整教学流程由主负责人在隔离浏览器运行；没有使用用户日常浏览器存储。

历史真实模型记录共39次（早期3次、第一轮25次、第二轮11次），来自第一份材料实验。关闭思考的v2提示词三个样本经严格引用检查后通过2个；不能将3次结果、段落命中数表述成稳定准确率。

本轮另用第二份方法类材料的文首连续45,000字符运行生产提示词3次：3/3通过结构、节点、段落和逐字引用自动校验，每次返回5条，耗时约22—41秒。三次节点与段落分布差异明显，因此只能证明接口与防伪引用链能工作，不能证明建议稳定、完整或有研究价值。完整材料为55,728字符，超出当前50,000字符上限，余下部分未评价。模型原输出仅保存在本机忽略目录。v2未替换生产提示词；AI仍为实验性辅助，建议必须经用户确认。人工盲评及真人试用尚未完成。本次发布不以它们冒充验收数据。

来源探针中腾讯30/30请求成功、东方财富9/30成功，9组可比窗口收盘值一致；仅说明该样本，不能推导长期服务等级或限流根因。既有容器记录为25/26来源成功、BLS返回403；空闲内存65.08MiB，峰值未测。依赖直接版本已固定，传递依赖未完整锁定。

## 交付限制

公开源码及本地启动流程优先。尚无免费且完成本项目验收的托管站点，因此不发布无登录保护的在线模型接口。容器是部署候选；上线仍需HTTPS、实际域名、持久卷、鉴权和真实环境资源核验。限流计数保存在内存，重启会清空。

个人研究记录保存在浏览器；没有账号同步、持仓导入、交易、实时推送或收益预测。观察里程碑由用户复核；新闻关联是标题关键词匹配，不是自动证伪。
