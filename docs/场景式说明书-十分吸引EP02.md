# 从一篇播客到可持续研究：十分吸引 EP.02 实操说明书

版本：v0.6｜实操验收：2026-10-12｜适用：本地服务与独立 HTML（能力差异见末尾）。操作内容保留v0.6范围，截图在v0.7回归时复核更新；新增能力见[补充说明](公司财务与核查修订-v0.7.md)。

### 2. 一次只归档一条可继续追问的观点

选择依据所在段落，填四项：保留的观点、框架节点、下一步验证问题、需要重新判断的条件。不要只填“很有启发”。例如：

- 观点：信用流向居民与地方政府，是检验价格拐点能否扩散的待验证条件。
- 位置：宏观环境 → 货币与金融。
- 问题：居民信用是否改善？先区分贷款余额同比与新增贷款。
- 重新判断条件：价格改善但居民信用持续偏弱，不能据此推出全面复苏。

点击“下一步：确认归档”，核对原文和归属，再确认。此次先不勾选持续观察，后面需要时再建。成功后点“继续整理同一材料”，不必重复导入全文。

## 路径三：我想知道数字到底能不能信

### 1. 为每个核查问题固定口径

打开研究链路 → “＋ 记录一项核查”，填写指标、材料值、单位、观察期、依据与限制，必要时附原始发布链接。有接入序列时可选择；没有时保留手工核查。

点击“按此期间对照缓存”只找**同一观察期**的数据，找不到就显示“缺少同期间数据”，不拿最新值替代历史值。公开数据刷新仍从原有刷新入口进行；这个按钮不是现场全网搜证，也不自动识别所有口径。

### 2. 本次八项核查结果

| 项目 | 记录与结果 | 正确的下一步 |
|---|---|---|
| 2026年8月PPI同比3.8% | 接口缓存同期间数值一致；另按原始发布抽样核对 | 保留同比、全国出厂价格口径，区别于环比和购进价格 |
| 2026年二季度汽车产能利用率70.8% | 原始发布抽样一致，手工记录 | 行业值不能当成某家公司利用率 |
| 汽车指数涨幅30% / 20% | 近10个月与年内1—8月，时间窗不同 | 先补指数名称、起止日，不判为自相矛盾 |
| 韩国销量3000 / 3002辆 | 可能为取整与精确值，仍待核原始值 | 补统计期间与原始来源 |
| 库存74天 | 待核实：样本、日期和算法不明确 | 区分厂家、经销商与渠道；库存预警指数不能替代天数 |
| 美债4.84% | 以纪要录制日推定“昨夜”为9月9日；DGS10同日缓存4.83%，标为“数值不同·待解释” | 纪要称盘中，日度观测不能直接证伪盘中报价；日期推定也需回听确认 |
| PPI传导指数<1 | 缺少定义、公式、窗口与样本 | 在可复现之前，不生成行业筛选结果 |
| 64%份额与“其余<30%” | 样本、期间、分母仍待核 | 同口径下才检查加总，不能擅自补齐其余部分 |

核查来源：[国家统计局2026年8月PPI发布](https://www.stats.gov.cn/zwfwck/sjfb/202609/t20260909_1965262.html)、[2026年二季度产能利用率](https://www.stats.gov.cn/sj/zxfbhjd/202607/t20260715_1964130.html)、[FRED名义10年期收益率DGS10](https://fred.stlouisfed.org/series/DGS10)。[中国汽车流通协会数据页](https://www.cada.cn/Data/list_85_1.html)是继续查库存的入口，本次未据此核实“74天”。

### 3. 主动保留反向线索

电池观点的反向线索来自同篇纪要34:34–35:19：电芯降价与产能过剩。价格叙事的反向线索来自40:25–41:09：涨价品类减少。这些线索也需要核实，但不应因为不支持原观点而被排除。

## 路径四：我希望下个月还能接着看

### 1. 从观点建立观察，避免另开一张失联的笔记

在研究链路点“从这条观点建立观察”，填写新闻标题关键词并确认。打开“叙事观察 → 我的观察”，点击主题下的“＋ 自定义里程碑”。填可观察条件、判定规则与来源、下次人工复核日。

| 主题 | 本次设置的里程碑 | 复核日期 | 为什么不直接自动判定 |
|---|---|---|---|
| 信用能否扩散 | 先统一居民贷款余额同比口径，再核对是否转正 | 2026-10-12 | 新增量与余额增速不同；转正也不足以证明复苏 |
| 油价→农业 | 先确认Brent/WTI、现货/期货，再查成本、种植和供需 | 2026-11-12 | “中高位”没有明确定义，不随意填写阈值；2027上涨是预测 |
| 价格扩散收窄 | 收集同样本同窗口分项，核对涨价品类变化 | 2026-10-12 | 总PPI不能替代分项扩散指标 |

这些日期是演示的人工复核安排，不是播客提供的事件发生时间。初始判定规则会保留，后续证据不会把规则覆盖掉。

### 2. 用反向材料修订，而不是只给观点加标签

点里程碑，选择“出现反证”，填写依据和信息日期后确认。本次把涨价品类减少记为对广泛回升的反向线索，并明确尚缺分项数据，未认定整体叙事失效。初始状态和本次变化均保留。

再打开电池观点 → “修订观点”，把原判断收紧为：

> 电池可能比整车有更强的价值获取能力，但纪要同时提示电芯降价与产能过剩；必须分公司核实，不能泛化为电池企业普遍受益。

填写修改理由，点击“对比变更”，看修改前后，再“确认更新”。本次记录从v1变成v2，原始段落定位不变。新增依据应写明来源；如有新文章，可另行导入保存全文。

## 已实现与仍然缺失的能力

| 能力 | 当前实现 | 边界 |
|---|---|---|
| 归档与来源 | 段落、纪要时间戳、问题、反证、版本 | 未核音频；这次为手动整理 |
| 关注排序 | 关键词与研究公司来源关联 | 非持仓分析、非语义推荐 |
| 传导与公司池 | 人工录入路径、公司理由、双向回溯入口 | 未自动生成产业图或受益名单 |
| 数字核查 | 手工口径记录、已接序列同期间缓存对照 | 非全网自动事实核查；部分数据仍缺失 |
| 叙事追踪 | 自定义里程碑、规则、复核日、证据历史 | 无自动阈值判定及站外提醒 |
| 日常新闻 | 原有来源与标题关键词匹配 | 不是全网资讯；本次没有捏造未来新闻命中 |
| AI辅助 | 接口入口与引用校验保留 | 本次未配置真实模型，未作真实AI效果验证 |
| 公司深研 | 可保存公司，原有估值与CSV技术指标入口 | 此次没有三家公司完整行情/财报接口验证 |
| 51个宏观指标Skill | 材料中提到的第三方工具 | 不属于本平台，不据此声称已经接入 |
| 部署 | 本地可运行、独立HTML可查看 | 尚未公开部署，也未经真实外部用户测试 |

本轮优先把“信息进入体系”的核心链路做实；后续接口扩充、模型效果评价和外部用户测试应分别验收。
