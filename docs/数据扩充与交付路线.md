# 数据扩充、全流程验收与作品集交付

调研日期：2026-10-11。本文件为下一轮实施依据，不代表下表候选数据已经上线。当前接通范围以 README 与数据源状态为准。

## 1. 当前定位

当前使用公开来源与 AKShare 采集适配器，没有连接付费金融终端。用户目前没有 iFinD 账号。iFinD 官方说明其 SDK/HTTP 接口具有账号权限和数据量限制，因此不能把开源数据适配器称为金融终端接入，也不把购买终端作为当前 demo 的前置条件。

来源：[同花顺接口基础概念](https://quantapi.10jqka.com.cn/gwstatic/static/ds_web/quantapi-web/help-center/faq.html)。若以后增加终端，先核对所购接口和展示权限，再映射到统一指标口径。

## 2. 分层指标候选

“优先”是产品实施建议，不是投资判断。每个子面板先保留 4–6 个核心指标，其他放到展开详情；不把整个候选清单同时铺在首页。

| 层次 / 研究问题 | 当前基础 | 下一批优先候选 | 后续候选 | 更新与展示 |
|---|---|---|---|---|
| 宏观增长：实际活动是否改善 | PMI | GDP 累计实际同比、工业增加值同比 | 社零、出口、城镇调查失业率 | 月度/季度；区分当月与累计，不把季度伪装成月度 |
| 宏观通胀：价格压力如何传递 | CPI、美国盈亏平衡通胀 | PPI 同比 | 核心 CPI、美国 PCE | 月度；市场隐含指标与统计指标分开 |
| 宏观金融：融资和资金价格如何变化 | M2、美国实际利率、美元广义指数 | 社融增量及分项、LPR | 中国国债利率、短端资金利率 | 社融亿元、利率%；避免只比较有季节性的环比 |
| 宏观政策：承诺何时执行 | 新闻与框架 | 政策发布时间、实施日、工具/影响对象 | 财政支出、政府债发行 | 政策事件时间轴配数据，不强行给叙事打分 |
| 黄金：谁在买、持有量是否变化 | 金价、利率、美元 | 黄金 ETF 持有吨数及变化、央行储备吨数变化 | 矿产金、回收金、首饰需求 | 区分吨数、美元流量和资产规模；储备资料存在发布滞后 |
| 黄金/白银：持仓与库存发生什么 | 当前未接 | CFTC 分项持仓、交易所库存 | 期限结构、现货升贴水 | CFTC 周度；库存按仓库/交易所分开，避免重复相加 |
| 白银：工业需求与供给能否匹配 | 白银合约价、产业链 | 年度矿产/回收供应、工业/光伏需求及供需平衡 | 光伏装机、单位耗银、替代技术进度 | 年度基本面与月度代理指标分区；预测与历史估计分开 |
| 公司经营：金属价格如何变成利润 | 手动公司记录 | 营收、归母/扣非利润、毛利率、ROE、资产负债率 | 金属产销量、实现售价、AISC、储量 | 财报与年报；矿山、冶炼、珠宝企业不同分组 |
| 公司现金流：增长是否回款 | 手动材料证据 | 经营现金流、资本开支、应收与存货 | 净债务、利息负担 | 季度/年度累计口径；季度转换与重述需记录 |
| 公司估值与市场表现：市场如何定价 | 手动倍数、CSV 技术指标 | 日线价格/成交量、PE TTM、PB、统一日期横向比较 | 历史估值区间、明确假设的情景估值 | 日度；亏损 PE 不排名；复权、股本、币种与报告期一致 |
| 叙事验证：什么证据会改变判断 | 模板与里程碑 | 将已有指标和证据关联到观察主题 | 提醒指标阈值/事件变化 | 不生成没有依据的成功概率、热度分或买卖建议 |

候选宏观与公司结构化接口参考：[AKShare 宏观文档](https://akshare.akfamily.xyz/data/macro/macro.html)、[股票文档](https://akshare.akfamily.xyz/data/stock/stock.html)。存在接口不等于已验证覆盖、及时性或可用性。

黄金来源：[世界黄金协会 ETF 数据](https://www.gold.org/goldhub/data/global-gold-backed-etf-holdings-and-flows)、[央行黄金储备](https://www.gold.org/goldhub/data/gold-reserves-by-country)。部分下载和筛选需要登录；公开可读不意味着已经获得自动化抓取和再分发许可。先核对获取方式，必要时使用带来源的人工导入。

白银来源：[世界白银调查](https://silverinstitute.org/all-world-silver-surveys/)。适合低频供需底图，不能把年度统计标为实时数据。新一期报告可能修订旧年份，应保留版本日期。

持仓来源：[CFTC COT](https://www.cftc.gov/MarketReports/CommitmentsofTraders/index.htm)。通常周五发布此前周二的观察值；明确使用期货单独口径或期货+期权口径，分类间不能混拼。

### 本轮接口试通结果

本地 AKShare 1.19.1 实测：PPI 返回 248 行、GDP 82 行、社融分项 136 行、山东黄金按报告期财务指标 97 行。仅说明当次请求返回非空结构化数据，尚未完成逐值原始来源核验、最新覆盖期验收或页面接入。[实测字段记录](候选数据接口实测.json)。

## 3. 数据接入验收门槛

每个指标记录：研究问题、来源链路、原字段、单位、频率、观察期、发布时间、获取时间、变换公式、修订和缺失规则。接口返回非空后，还需与原始发布对齐至少一个观察值，再接入页面。

分三类交付：自动获取的时间序列；人工核验导入的低频表格；尚未取得的待接入项。后两类不冒充自动实时接口。价格、持仓和需求量不能互相替代。

首批实施顺序：补 PPI/社融等宏观缺口 → 接公司财务与日线 → 补黄金持仓/储备和白银年度供需。GDP 必须先核对累计/当季口径；AISC 和单位耗银无法直接从一般财务比率接口得到，需来源核验。

## 4. 用材料走完功能：三份互相关联的交付物

| 文档 | 面向谁 | 回答什么 |
|---|---|---|
| PRD | 产品、设计、开发及评审者 | 为谁解决什么问题；业务规则、边界、异常状态、验收标准与范围取舍 |
| 使用说明书 | 第一次打开产品的人 | 从哪里点起、准备什么材料、每步会得到什么、怎么修正和找回 |
| 验收与迭代记录 | 开发者、评审者、项目使用者 | 哪个版本用什么材料跑了什么场景，预期和实际是否一致，发现什么问题、怎么修复 |

同一场景可以同时成为 PRD 验收条件、测试用例和说明书示例，但三者用途不同。可以先用当前草稿验证产品，再重写反映最终行为的 PRD；不能事后编造需求证据或用户效果。

### 全流程验收清单（待执行，不算当前已通过）

| 场景 | 材料与动作 | 应保存的结果 |
|---|---|---|
| 第一次日常研究 | 宏观数据 → 金银数据与新闻 → 两家公司比较 | 数据日期、来源解释、跳转与理解障碍 |
| 材料归档 | 用户授权使用的播客笔记，拆出不同层次观点 | 段落定位、候选归类、人工修正、最终证据 |
| 叙事追踪 | 光伏技术变化示例；后续补一条反证材料 | 初始假设、采用模板、里程碑与修订历史 |
| 财报与价格 | 两家业务可比公司的公开财报及明确复权口径的日线 | 口径核对、横向比较、指标计算与缺失处理 |
| 异常与恢复 | 断网、失败来源、未配 API、错误 CSV、刷新与关闭重开 | 可理解的提示、缓存状态、备份导出与恢复 |
| 真实 AI | 用户本地配置 API 后显式分析一份材料 | 引文准确性、错分与幻觉检查、人工修改记录 |
| 陌生用户试用 | 让未参与设计的人按说明书独立完成任务 | 卡点、耗时和反馈；未经实际测试不填成绩 |

公开演示优先用可公开引用的材料或标注清楚的原创样例。实习课件与私人笔记不随部署上传。真实 AI 与人工/规则辅助分别验收，不互相代替。

说明书结构：产品适合谁 → 3 分钟开始 → 两条完整研究路线 → 每个功能操作 → 数据/AI边界 → 失败与恢复 → 常见问题。每个步骤提供截图、操作、预期结果和下一步。另准备 3–5 分钟演示脚本，避免项目使用者需要读完整 PRD 才能上手。

## 5. 线上展示的路线

最终需要项目使用者能直接打开的体验链接，并配代码仓库和文档。本轮未部署，也未创建付费资源。

- 展示版本：浏览器中的归档、模板和本地保存，加明确日期的公开数据快照。这种版本可静态托管，但不能称为完整在线 AI/数据服务。
- 完整在线版本：运行当前 Python 数据采集与计算服务，服务端管理模型密钥、超时/限流、数据缓存与定时更新；需要适配生产运行环境。当前 127.0.0.1 本地服务不可原样视为公网就绪。
- 上线前明确访问与费用：项目使用者能否免登录体验、AI 请求额度与失败回退、个人材料如何隔离、数据展示权限以及云端来源可达性。现有浏览器本地保存可以保留，不需要为演示立即做多人协作。
- 从部署环境再验收：页面打开、数据刷新、失败提示、材料归档、AI显式发送、手机访问。不能用本地成功代替云端实测。

建议顺序：指标扩充与来源核验 → 全功能真实材料验收 → 使用说明书和 PRD 更新 → 线上部署与线上复验 → 邀请外部试用并记录迭代。
