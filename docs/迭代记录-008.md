# 全功能流程补充验收与说明书汇总

日期：2026-10-12｜产品仍为v0.7，本轮新增验收材料与教学输入，没有宣称新接口已经上线。

## 目的

补齐此前只有功能入口或分项测试、缺乏完整用户操作记录的估值、价格计算、新闻观察与异常恢复流程。保存历史说明书，新建综合试用说明书，不覆盖旧版本。

## 本轮执行

- 两家非真实教学公司，录入同报告期不同日期估值，验证日期差异提示；统一日期后验证口径一致提示。保留负PE，页面不把它解释为更便宜。
- 重复日期CSV被拒绝，首次不生成结果；一条价格时指标留空；50条合成数据实际调用TA-Lib，A的MA20=139.5、RSI14=100，B的MA20=239.5。成功结果后再次错误导入，原结果保留。
- 公开缓存的美联储新闻按来源筛选，带入研读后只填标题和链接，正文等待用户补充。
- 模板预览不订阅，保存后产生三个里程碑；延期缺少理由时拒绝保存，补齐后留存。
- 新闻关键词匹配、标已读、暂停、编辑主题及恢复；关闭来源后在面板过滤，再恢复开关。
- 错误schema备份被拒绝且状态不变；正确教学备份在新浏览器重复导入两次，保持两家公司、一个观察，没有重复，价格计算值与刷新保存均通过。
- 离线页面的AI按钮不可用；另用独立模拟响应测试AI迟到结果保护、候选观点及确认归档。

## 结果

`tests/full-workflow-smoke.cjs`通过，无页面脚本错误。`tests/ai-ui-smoke.cjs`通过，明确为模拟模型。Python契约16/16通过。八张新截图保存在`docs/scenarios/full-workflow/`；两张主要页面已人工查看。测试原始结果与教学备份在忽略目录`data/test-artifacts/full-*/`。

新增公开教学CSV及其说明位于`examples/`，文件均为合成值，不是真实行情。没有把合成估值或价格放到真实公司名下。完整综合说明书位于`docs/全功能使用说明书-v0.7.md`，逐项标注真实数据、教学输入、模拟接口与待验证范围。
