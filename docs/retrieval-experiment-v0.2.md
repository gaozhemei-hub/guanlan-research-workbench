# 检索方案对比实验 v0.2

日期：2026-10-25。范围是独立离线实验，产品尚未接入 RAG 问答或浏览器同步。本轮无付费 API 调用。

## 为什么扩大实验

v0.1 只有 8 个单段来源，找到来源不代表找全证据。本轮改用 12 篇、24 段原创教学材料及 17 个问题，按段落标注必需证据，覆盖不同统计期间、相反条件、跨来源关联，以及有相关文字但没有答案的问题。

材料、问题与标签均由 AI 编写；不是独立人工评审，也不是真实投资资料。开发组 6 题（5 题有答案），比较组 11 题（8 题有答案）。比较组现已运行，不能再称为未见盲测；没有根据本轮结果修改参数或标签。冻结文件为 `examples/retrieval-benchmark-v2.json`，SHA256：`bc19dd1c1960df367b139d5f4bff2371f248cd803989b2dc8d27f643da8f8df1`。

## 对比方法

- 词法：沿用中文双字片段 BM25。
- 向量：本机 CPU 运行 [BAAI/bge-small-zh-v1.5](https://huggingface.co/BAAI/bge-small-zh-v1.5)，查询添加模型卡建议的中文检索指令，段落不添加。归一化向量点积排序。MIT 许可；复用模型，不声称自训模型。
- 混合：词法与向量各取前 10 条，以倒数排名融合（RRF，常数 60），再取前 3 条。参数在查看本轮结果前固定。
- 重排：对混合前 10 条用 [mmarco-mMiniLMv2-L12-H384-v1](https://huggingface.co/cross-encoder/mmarco-mMiniLMv2-L12-H384-v1) 评分，再取前 3 条。该模型为多语言 CrossEncoder，Apache-2.0 许可；本轮已在本机执行。

模型只在首次下载时访问模型托管站；原创测试文本在本机推理，不调用托管推理 API。模型权重、索引与运行原始记录不进入 Git。

## 四方案完整运行结果

比较组 8 道有答案题，返回前 3 个段落：

| 方法 | 平均必需段落召回率 | 找全必需证据的题目比例 | MRR@3 | 单题平均耗时 |
| --- | ---: | ---: | ---: | ---: |
| 词法 | 66.7% | 50.0% | 0.750 | 0.61 ms |
| 向量 | 89.6% | 75.0% | 0.938 | 7.66 ms |
| 混合 | 77.1% | 62.5% | 0.750 | 8.27 ms |
| 混合加重排 | 95.8% | 87.5% | 1.000 | 69.40 ms |

每题召回率是已召回必需段落数除以标签要求段落数，再取平均；找全率要求所有必需段落都出现。MRR 仅考虑第一个相关结果，因此不能替代找全率。时间是这次小语料、CPU 运行的观测，向量时间含查询编码，不含模型下载、加载和预建段落向量；不是产品性能承诺。

四种方法都对比较组 3 道无答案题返回候选。当前没有拒答或充分性判断，不能把非空检索结果当成可回答，更不能把这张表写成回答准确率。

初步发现：向量改善了同义表达问题；简单混合没有自动带来提升。向量仍漏掉黄金问题中的相反力量，以及公司关联题的部分必需证据。暂不因技术复杂度选方案，也不依据这组小样本决定生产默认配置。

混合加重排在 8 道有答案题中有 7 道找全，改善了本组样本的覆盖，但仍在公司关联题遗漏收入结构的段落。首个相关结果全排第一（MRR=1）并不意味着证据全部齐全。重排耗时也更高。下一步将其作为待验证候选，继续保留纯向量对照；不能据此声称任何方案已在真实用户场景胜出。

第一轮原始报告位于本机忽略目录 `data/retrieval-comparison/1792865715596189000.json`；它记录每题预期/实际段落、模型版本、依赖、样本哈希和耗时。BGE 固定修订为 `7999e1d3359715c523056ef9478215996d62a620`，加载上限 512 tokens，样本最长 72 tokens；代码检测越界后失败，不静默截断。仍未实现真实长文的 token 分块。

上表使用第二次四方案完整运行 `data/retrieval-comparison/1792865898537883000.json`，三种原方案的排名指标与首轮一致，耗时有所波动。重排模型固定修订为 `1427fd652930e4ba29e8149678df786c240d8825`，使用 512-token 限制，最长问题/段落对 69 tokens。首次下载与初始化约 138 秒，已与单题推理时间分开记录。原始报告只在本机保存，公开此汇总与原创样本。

## 复现与验收边界

产品环境不变；可选实验环境使用 Python 3.12，安装 `requirements-rag.txt`。这仅固定直接依赖，不是全平台完整锁文件。本机完整环境快照保存在忽略目录的 `environment-2026-10-25.txt`。

```sh
python -m venv .venv-rag
.venv-rag/bin/python -m pip install -r requirements-rag.txt
.venv-rag/bin/python scripts/compare-retrieval.py --vector --revision 7999e1d3359715c523056ef9478215996d62a620
# 如需复现重排，添加：
# --rerank --reranker-revision 1427fd652930e4ba29e8149678df786c240d8825
```

不带 `--vector` 只运行词法，不下载模型。常规 `scripts/verify.py` 不运行模型下载或推理。新增两个指标测试，验证部分证据不能算找全、无答案候选单独计数及融合深度；本轮后端 74/74 通过。界面未改，本轮未重跑界面，上次 15/15 是上一阶段结果。

下一步仍需更大的独立语料、长文分块、证据不足处理，以及浏览器显式同步与引用回跳。尚未开展人工盲评或真人试用。
