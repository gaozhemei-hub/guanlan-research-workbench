# 交付进度与剩余步骤

更新：2026-10-12｜当前产品v0.8。

已有成果：本地研究工作台、宏观—贵金属—公司底座、真实播客四条动线、五个财务样本、核查与修订、观察主题、备份、教学与真实价格计算。各版文档与截图继续保留。

| 阶段 | 当前状态 | 完成条件 |
|---|---|---|
| 1. 真实行情 | 两家公司真实取数、缓存、预览保存与CSV复算已验收；更新稳定性未完成 | 补齐失败样本，核查来源、窗口和复权，在实际部署环境验证刷新 |
| 2. 真实AI | 尚未配置本地API；模拟流程和引用校验已测试 | 用真实材料测试引用、分段、归类和不确定性；记录错误样本、耗时与费用，完成修复 |
| 3. 提醒机制 | 页面内到期复核与新闻匹配可用 | 先限定可自动判断的指标与阈值；叙事事件保留人工确认；再确定需要的通知方式 |
| 4. 线上部署 | 尚未部署 | 决定公开演示范围，隔离个人材料，服务端保管密钥，限制请求额度，验收来源连通与费用 |
| 5. 最终交付 | 版本文档齐备；综合说明书为试用版 | 外部用户独立完成任务，记录与修复问题，汇总说明书，以验收结果定稿PRD，整理仓库及体验入口 |

真实API密钥只填本机`.env`或部署平台的服务端密钥配置，不写入聊天、前端、截图或公开仓库。没有模型配置时，可并行完成行情稳定性和部署方案准备。

最终说明书将综合现有文档，不删除历史案例与版本证据。公开材料只描述产品、使用方法、技术实现和验收结果。
