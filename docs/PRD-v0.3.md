# 观澜 PRD v0.3 · 发布状态补充

日期：2026-10-13。适用产品：v0.8.1。本版与[完整PRD v0.2](PRD-v0.2.md)共同组成需求基线；背景、用户、范围、页面与数据模型沿用v0.2，以下冲突处以本版为准。v0.1和v0.2保留原状作为历史版本。

## 已确定的交付决策

| 原编号 | 本次决定 | 验收及尚未完成部分 |
|---|---|---|
| D01 行情 | 腾讯优先、东财备用；完整区间单来源；保留复权和缓存元数据 | 仅五只验证代码；有限样本成功率不能代表长期可用性 |
| D02 AI | 兼容接口、逐字引用校验、用户确认；引用去除加粗后至少6字符，最多5条建议 | 第二份材料3次自动校验通过，但输出分布差异明显；AI实验性，v2未替换生产提示词；人工盲评不作为本次源码发布前置，仍未完成 |
| D03 观察 | 待核查/延期需有效复核日期，延期日期必须晚于当日；到期重新提示；暂停不提醒 | 本次不集成自动数值触发或站外通知；历史记录保留旧/新日期 |
| D04 发布 | 工程验收后公开源码；体验站必须有登录保护；不新增部署费用 | 未部署体验站；免费托管适配未验收，不把本地容器当线上站点 |
| D05 数据安全 | 写入失败统一回滚研究状态并中止成功反馈；材料草稿保留内存并明确未保存 | 其他未保存表单可丢失；同代码不同ID和多标签并发未解决，不做静默合并 |
| D06 用户验证 | 人工盲评和真人试用延期 | 不把AI模拟测试记为用户，不填写用户满意度/效率提升 |
| D07 文档 | 保留阶段文档，增加最新操作总入口与验收记录 | 实施结果和未完成事项优先于历史文档的状态描述 |

## 核心验收更新

N01保存可靠性及R14备份：注入存储失败后旧记录不改变、无成功提示，草稿可导出；恢复存储后可重试。备份字段不能注入脚本，错误文件不改变当前数据。

R05 AI：迟到响应不覆盖手动编辑，更换依据段落撤销已校验标签。输出校验失败不归档；引用匹配不等于事实成立。

R16访问控制：非本机监听必须配置服务端认证及域名；静态GET/HEAD和API要求登录，健康检查仅返回存活状态。公开站点需要HTTPS；内存限流不是持久额度账本，模型调用默认关闭。

## 发布验收证据

合并后主项目64项后端测试、15项界面测试通过，完整教学流程通过；候选当前9个冒烟脚本通过。界面测试中含模拟AI，价格计算包含合成序列。旧v0.1测试属于历史版本范围。详情见[发布验收](发布验收-2026-10-13.md)。

当前未完成：真人可用性验证、模型跨材料人工质量验证、容器最新变更重新构建后的全流程、真实在线托管、峰值资源测量、全量传递依赖锁定。它们限制对线上质量与产品效果的表述，不被工程通过数替代。
