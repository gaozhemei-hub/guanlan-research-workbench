# v0.6：从播客到研究体系的四条真实动线

日期：2026-10-12。配套：[场景式说明书](场景式说明书-十分吸引EP02.md)。

## 为什么改

旧说明书按页面解释功能，缺少“听到观点之后如何继续研究”的完整案例。使用用户的20,331字符播客纪要实测，发现旧20,000字符限制无法完整导入；观点、公司与观察之间也缺少清楚的来源关系。

## 本轮改动

- 导入与AI分析正文上限统一为50,000字符；文件上限200 KB，服务请求上限不变。
- 新增“我的研究线索”，按用户关键词与公司关联作规则排序；未命中内容保留。
- 保存纪要段落对应时间戳，并允许修正；明确未回听音频。
- 新增观点研究链路：传导路径、关联公司、核查项、建立观察和修订入口。
- 公司保留来源观点ID，支持“为什么研究它”返回研究链路及关联已有公司。
- 核查记录保留期间、单位、来源、状态；可按同一期间对照已接数据缓存，缺失不拿最新值替代。
- 新增FRED DGS10名义10年期收益率，与原有DFII10实际收益率区分。公开来源目录23项，不代表23项都始终抓取成功。
- 普通观察主题可添加行业/叙事里程碑、初始规则、复核日、状态与证据历史。到期提示仅在页面内，不做自动事实判定或站外推送。
- 保持schema 2向后兼容，新增字段可选；备份校验覆盖研究路径、公司来源关联及复核日期。
- 修正空研究线索页的引导显示；打包更新独立HTML和公开快照。

## 实操产出

独立浏览器中使用真实完整纪要，归档六条观点，关联三家公司，保存八项核查、三个观察主题与三个自定义里程碑，完成一次电池观点v1→v2修订。保存八张截图，生成本机私有案例备份。没有把个人材料注入默认产品状态或公开快照。
