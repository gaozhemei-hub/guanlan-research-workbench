# 迭代 002：从材料列表到有研究骨架的工作台

日期：2026-10-11。产品方向和范围来自用户本轮确认；本记录不是 PRD，也不声称已完成外部用户验证。

## 为什么改

旧版以材料记录为中心，框架、指标和线索平铺在三个 Tab。用户反馈不知道怎么走完流程，且内容像靠用户自行拼凑的方法集合。

新方向：平台预置方法底座；日常看数看信息与主动导入材料分开，最后都回到同一组研究问题。

本轮用户确认：公司研究先聚焦 **A 股贵金属相关公司**；没有金融终端账号；已有模型 API，稍后本地配置。

## 改动

- 主导航：研究总览、宏观环境、贵金属产业、A 股公司、叙事观察、材料研读、数据与设置。
- 宏观按增长、通胀、政策、货币金融组织；每个节点有核心问题、传导路径、观察项、反证条件和方法出处说明。
- 黄金与白银分别建框架；供应链展示矿产/回收、冶炼/精炼、消费/持有。定价参与者单独说明，不伪造企业供应关系。
- 公司分经营、估值、技术三个视角；可记录研究对象与业务位置，录入估值快照，导入价格并计算。日期、报告期、币种、复权方式分别标注。
- 材料流程改为三步：导入 → 拆解归类 → 确认归档。归档后可直接跳到框架中的证据；每条记录保留完整原文和段落号。
- 每次归档一条观点，支持同一材料继续整理。正文变动会使旧拆解失效。AI 调用中途更换材料时，旧结果不应用。
- 观察主题关联框架节点，保存验证问题、反证条件、关键词；可暂停、编辑、查看已接入新闻的标题匹配并标已读。
- 判断修订先展示前后对比，再确认增加版本；原有观察主题保留原假设，由用户决定是否单独修改。
- 原版界面归档；旧浏览器键不删除，新版保留旧记录副本并提供复制入口。新增全量备份及按 ID 合并导入。

## 遇到的问题与处理

- Python HTTPS 请求初次遇到证书验证错误：补齐 certifi，继续保持 TLS 校验，不使用跳过证书的做法。
- BLS 返回 403：保留可见失败状态，未试图绕过访问限制。
- 一次本地服务启动审批因额度导致审批执行失败；用户要求继续后正常重试成功。未绕过审批运行同一动作。
- 扩展浏览器测试最初误统计已关闭弹窗中的新闻元素：限定到当前页面后，订阅过滤验证通过。
- 备份读取是异步操作：测试等待实际读取结束后再检查错误提示，避免把未完成读取当作功能失败。
