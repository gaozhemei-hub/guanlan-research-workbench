## 从“为什么研究它”继续走向财务证据

1. 在“数据与设置”导入本机的EP.02案例备份，或手动添加研究公司。
2. 打开“A股公司 → 公司与业务”，在公司卡片点击“查看财务”。
3. 财务面板自动切换至“我的研究公司（已支持的代码）”，以证券代码关联公开财务。案例中的宁德时代、比亚迪、亿纬锂能进入同一报告期的表格。
4. 选择报告期，查看营收、归母净利润、扣非净利润、毛利率、ROE、资产负债率和每股经营现金流。来源卡保留披露日期、报告期末、币种和成功抓取时间。
5. 数据可能支持追问，但不足以直接证明“电池比整车更能获取价值”。比亚迪包含整车等业务，其他公司也有不同业务结构；分部、价格、产销量与投入仍需读原始报告。

比较范围可以切换：贵金属样本（山东黄金、盛达资源）、我的研究公司、全部五家公开样本。默认保留贵金属视角。只有五个受支持代码会被接入；添加其他代码时会列明“尚未支持”，不拿另一家公司数据替代。名称与代码由用户输入，接口关联代码不等于核验了输入名称。

## 核查项可以继续修订

以前的“库存74天”只有待核查记录。现在可以从观点的“打开研究链路”找到该项，点击“补充核查依据”：

1. 检查材料值、单位、观察期与来源。
2. 补上新依据，或明确仍缺什么。如果指标期间、定义没有核实，就保持待核实，不强行变成已验证。
3. 保存后更新同一条核查，不新增重复项。
4. 展开“核查历史”，查看之前的状态、依据、期间、数值与单位。修订并刷新页面后仍保留。

修改曾经自动对照的核查项时，需要重新选择人工核查状态；缓存对照结论不会被直接继承为修改后仍然成立。再次对照时仍只匹配同一观察期。

本轮演示中，库存项补充了“缺统计期间与库存天数公式，不能用库存预警指数替代”，仍保持待核实。这是研究进度的真实记录，不把“填写了更多文字”当成完成核验。
