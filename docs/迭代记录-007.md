# v0.7：案例公司财务关联与核查修订

日期：2026-10-12。

## 问题与变化

v0.6可以把播客观点关联到公司，但三家汽车/电池案例公司还没有财务数据；核查记录建立后，也缺少继续补充证据的入口。

本轮复用已安装的AKShare财务接口，新增宁德时代300750、比亚迪002594、亿纬锂能300014三家公司。与原有两家贵金属样本合计五家；没有扩展为全市场接口。公司列表新增“查看财务”，按用户保存的代码筛选同期数据；可切换贵金属、个人研究公司和全部样本。未支持的代码列明缺口，不替换为其他公司。

核查项新增“补充核查依据”和历史展开。修改保留同一ID、旧状态、依据、期间、单位和数值；与同期间缓存再次对照也记录旧状态。编辑后的人工状态需要重新确认，不自动继承旧的对照结论。

## 数据实测与故障

三家新增公司均取得16期有效财务记录，最新为2026-06-30。仍按证券代码和披露日期过滤，未披露或未来日期不展示。公开快照仅保留最近8期，完整缓存留在本地；公开来源目录扩充到26项。

首次并行抓取超过35秒限制。诊断堆栈显示AKShare冷启动导入curl_cffi等依赖期间耗时；依赖加载后，同一AKShare函数取得真实数据，常规受35秒限制的抓取也返回成功。没有提高常规超时上限或关闭证书校验；其他机器冷启动仍可能超时，可重试，失败时显示状态并保留缓存。
