# v0.4：宏观缺口与公司财务面板

2026-10-11。本轮完成第一批数据扩充，不代表全部交付路线已完成。

## 实现

新增 PPI 同比、社融当月增量、1 年期 LPR；新增山东黄金和盛达资源财务样本。公司页「财务面板」支持选择报告期，展示七项指标、报告期末、披露日期、币种和来源。默认优先选择两家共同报告期；没有对应报告显示缺失，不偷偷用其他季度代替。

财务原始金额以元保存、CNY 页面换算为亿元；百分比不再乘 100。收入、利润和每股经营现金流使用累计报告期，ROE 不年化；缺失值不变成零。证券身份不符、未来披露日期记录被排除。失败保留旧报告并显示旧缓存。

当前只覆盖两个固定样本，不随个人公司列表动态扩展；不提供推荐排名。AISC、产销量、资本开支、完整现金流总额和自动股价仍待接入。GDP 接口试通，但累计口径与修订处理尚待完成，本轮没有上页面。

## 本版快速试用

1. 打开独立 HTML，或启动本地服务。
2. 宏观环境 → 通货膨胀 → 数据面板：查看 CPI 与 PPI 的单位和观察月份。
3. 切到货币与金融：查看社融日期及旧覆盖提示；宏观政策中可查看 LPR。
4. A 股公司 → 财务面板 → 选择 2025-06-30：山东黄金营收显示 567.66 亿元、盛达资源 9.06 亿元。
5. 阅读表下的披露日期和来源；金额大小不是投资优劣排名。
6. 点击“带着问题去读财报”，进入材料研读，归类预置为公司经营；继续使用既有归档流程。
